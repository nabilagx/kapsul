# KAPSUL 🌱

**Aksi kecil, dampak besar.** KAPSUL is a mobile-first environmental action and rewards PWA prototype.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What's inside

- **Home:** campus selector, PM2.5 air-quality indicator, weekly capsule, energy progress, and impact summary.
- **Misi:** low-emission commute challenge, waste-sorting photo upload, and referral challenge.
- **Dompet:** sample partner vouchers and a digital impact receipt.
- **Loot Box:** capsule reveal, sample reward, savings estimate, and share action.
- **PWA:** install manifest, app icon, and basic service-worker caching.

## Tech stack

- Next.js 15 + React 19
- TypeScript
- Lucide React
- Custom responsive CSS
- Web App Manifest + Service Worker

## Prototype disclaimer

This repository is a front-end demonstration. User identity, GPS verification, live air-quality readings, QR/waste-drop-off verification, voucher redemption, and reward settlement are **not connected to production services**. Mission completion and environmental impact figures are simulated and should not be interpreted as verified measurements.
